# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful, and productive environment for everyone, regardless of background, identity, experience level, or technology preferences.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while remaining precise about technical facts.
- Accept feedback gracefully.
- Focus discussions on code, configuration, documentation, and project goals.
- Respect differing levels of experience.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing another person's private information.
- Sharing credentials, private keys, certificates, or other sensitive material.
- Trolling, insulting, or deliberately disruptive behavior.
- Publishing others' private communications without permission.

## Enforcement

Maintainers may edit, remove, or reject contributions, comments, issues, and pull requests that violate this code of conduct. Repeated or serious violations may result in a temporary or permanent block from participating in the project.

## Reporting

Report conduct concerns privately to the repository maintainer. Include links, timestamps, and any relevant context.
